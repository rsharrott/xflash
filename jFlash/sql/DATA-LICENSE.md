  derivative work; every other 1.x card was replaced by its JMdict entry.
* Core 1000 is not a separate word list. It is the cards in this dictionary
  whose JMdict entry carries the nf01 or nf02 priority tag (the first two

  (sha256 `aacc8703771759ad302f01199db13e83043fdf8cabb2357df742e9e758e8aa8d`)
  because the 2026-10-18 file is no longer published. The card text itself is
  still the 2026-10-18 build. The bands are part of JMdict and are covered by
  the same CC BY-SA 4.0 licence. The set has the 993 entries that carry those
  tags. It is not padded to 1,000.

  under CC BY 2.0 FR. The sentence/card links were generated by
  `tools/dictbuild/`.

  membership only.
